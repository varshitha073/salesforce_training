---

# 1.🌟 What is LWC?

Lightning Web Components (LWC) is a modern UI framework provided by Salesforce for building fast and reusable web components.

It uses:
- HTML
- JavaScript
- CSS

---

# 2.⚡ Why Salesforce Uses LWC

Salesforce uses LWC because it provides:

✨ Faster performance  
✨ Reusable components  
✨ Better security  
✨ Modern JavaScript support  
✨ Easy integration with Salesforce data  
✨ Lightweight architecture  

LWC improves user experience and makes application development easier and cleaner.

# 5.🔥 Frontend vs Backend Logic

| Frontend (UI/LWC) | Backend (Apex) |
|-------------------|----------------|
| Button clicks | Database operations |
| Form design | Data validation |
| Notifications display | Fee calculation |
| User interactions | Record insert/update |
| UI animations | Security handling |
