# Salesforce Admin Track – Day 5  
## Lightning Experience & Lightning App Builder

---

## What is Lightning Experience?
Lightning Experience is Salesforce’s modern user interface designed to improve usability, speed, and productivity.

- Modern UI with better navigation
- Faster performance than Classic
- Customizable layouts
- Mobile-friendly design
- Supports drag-and-drop components

---

## What is Lightning App Builder?
Lightning App Builder is a **no-code tool** used to customize Salesforce pages.

It allows admins to build:

- Home Pages
- Record Pages
- App Pages

Key features:
- Drag-and-drop components
- Dynamic visibility rules
- Real-time UI customization
- No coding required

## Reflection

### Why should different users have different user interfaces?

- Different roles need different information
- Reduces unnecessary data overload
- Improves productivity and focus
- Enhances user experience
- Prevents confusion in workflows
- Improves decision-making speed
- Supports role-based responsibilities
- Increases system efficiency
- Reduces training requirements
- Aligns UI with job functions
