# 📊 Salesforce Administrator Track – Day 2: Reports & Dashboards

---

## 📊 What is a Report?

A **Report** in Salesforce is a list or summary of records that meet specific criteria. It allows users to filter, group, and calculate data.

### 🔹 Key Features:
- Displays data in tabular or summarized format
- Supports filtering and grouping
- Can include formulas and charts
- Stored in report folders

---

## 📈 What is a Dashboard?

A **Dashboard** is a visual representation of data from reports. It displays key metrics using charts, graphs, and widgets.

### 🔹 Key Features:
- Built using reports as data sources
- Shows KPIs and trends visually
- Supports multiple components in one view
- Helps in quick decision-making

---

## 🔄 Difference Between Reports and Dashboards

| Feature | Reports | Dashboards |
|----------|--------|------------|
| Definition | Structured data list | Visual representation of data |
| Format | Table / Summary | Charts / Graphs / KPIs |
| Source | Salesforce records | Reports |
| Usage | Data analysis | Decision making |
| Customization | Filters, grouping | Widgets, layout |

## 📋 Five Important College Reports

### 1. Student Attendance Report
- **Data Needed:** Attendance records, student details
- **Viewers:** Faculty, Principal
- **Refresh:** Daily / Weekly

### 2. Placement Status Report
- **Data Needed:** Student placements, company details
- **Viewers:** Placement Cell, Management
- **Refresh:** Weekly

### 3. Faculty Workload Report
- **Data Needed:** Faculty assignments, subjects, hours
- **Viewers:** HOD, Admin
- **Refresh:** Monthly

### 4. Internship Tracking Report
- **Data Needed:** Internship status, student details
- **Viewers:** Placement Cell
- **Refresh:** Weekly

### 5. Student Performance Report
- **Data Needed:** Marks, exams, academic records
- **Viewers:** Faculty, Management
- **Refresh:** Monthly

## 🎯 Reflection

Reports and Dashboards are critical for understanding business performance. They convert raw data into meaningful insights that help leaders make fast and accurate decisions.

Without reports, data is unorganized. Without dashboards, data is not visualized effectively.

Together, they form the backbone of Salesforce Analytics.
